# Tarot assets

This directory contains the compact DogeReader tarot deck used by the X4 Pro
Tarot activity and Tarot standby screen:

- `cards/`: 78 full card images (320x533 BMP)
- `thumbs/`: 78 history thumbnails (80x133 BMP)
- `meanings.json`: card names and short meanings

Copy this whole directory to `/tarot/` at the root of the reader's SD card.
The source assets and original Tarot app are from
<https://github.com/TinkerDoge/DogeReader> and are included under the MIT
license in `LICENSE.DogeReader`.
